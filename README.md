## 📌 Overview

**NutriLens – AI-Based Smart Meal Analyzer** is an intelligent AI-powered application developed to help users maintain healthier eating habits through smart meal recognition and nutrition tracking.

The system allows users to **scan food images, upload meal photos, or manually enter meal details** to receive instant nutritional information such as **calories, protein, fats, carbohydrates, and health score**.

Using the **Google Gemini API**, NutriLens performs **AI-based food recognition and nutritional analysis**, helping users understand the nutritional value of meals and make better dietary decisions.

---

## 🚀 Features

✅ **AI Food Recognition** – Detect food items using AI-powered image analysis.  
✅ **Meal Scanning** – Capture meal images using camera or upload photos.  
✅ **Nutrition Analysis** – Get calories, protein, fats, and carbs instantly.  
✅ **Health Score** – Receive nutrition insights for healthier eating.  
✅ **Meal History** – Save and track previous meal records.  
✅ **Weekly Reports** – Monitor nutrition trends and dietary habits.  
✅ **Profile Management** – Set calorie goals and health preferences.  
✅ **Responsive UI** – Smooth and user-friendly interface.

## ❗ Problem Statement

Many people struggle to maintain healthy eating habits due to a lack of nutritional awareness. Traditional calorie tracking methods require manual food entry, which can be time-consuming and inconvenient.

**NutriLens** solves this problem by using **AI-powered food recognition** to instantly analyze meals and provide nutritional insights.

## ⚙️ Installation Guide

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/NutriLens.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd NutriLens
```

### 3️⃣ Install Dependencies

```bash
npm install
```

### 4️⃣ Setup Environment Variables

Create a `.env` file in the root folder and add:

```env
VITE_GEMINI_API_KEY=your_api_key_here
```

### 5️⃣ Run the Project

```bash
npm run dev
```
